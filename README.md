# Сайт колледжа IT STEP Астана

## Проблема
Школьникам после 9 класса и студентам, желающим перевестись из другого колледжа, сложно быстро найти понятную информацию о поступлении: какие программы предлагаются, как проходит зачисление и куда обратиться. Сайт закрывает эту потребность, собирая всю ключевую информацию и контакты в одном месте.

## Пользователь
- Школьник, рассматривающий поступление в колледж после 9 класса.
- Студент другого колледжа, желающий перевестись.

## Возможности
- Информация о программе обучения и IT-специализациях колледжа.
- Описание этапов поступления.
- Контактные данные (адрес, телефоны, email, соцсети) и форма заявки/записи на консультацию.

## Запуск локально
1. Склонировать репозиторий:
   ```
   git clone https://github.com/e91337358-cloud/dayn.git
   ```
2. Перейти в папку проекта:
   ```
   cd dayn
   ```
3. Открыть `index.html` в браузере (двойным кликом или через "Открыть файл").

Все стили (`college.css`, `overrides.css`) и скрипты (`college.js`, `common-gps.js` и др.) подключаются напрямую из `index.html`, отдельная сборка не требуется.

Для запуска через локальный сервер (по желанию):
```
npx serve .
```
или в VS Code — расширение Live Server.
